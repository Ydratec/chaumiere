# Modules métier

Chaque module contient sa logique métier, ses types et ses validations.

Modules prévus :
- auth : authentification et sessions
- users : profils utilisateurs
- rooms : salles, membres et permissions
- questions : questions quotidiennes et réponses
- codenames : parties et règles du jeu
- chat : messages et discussions
- notifications : notifications

Les modules ne doivent pas dépendre directement des composants d'interface.
